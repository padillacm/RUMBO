# Human decisions log (the compass)

The human writes down what was decided and why. The agent proposes; the human decides.
Format: `## YYYY-MM-DD — title` + decision, why, who. (Shortcut: `rumbo decision`.)
Also log when a spec closes and how many sessions it took (`rumbo decision "F-0001 closed" --why "1 session"`):
that number is the team's own measure of whether tasks fit the agent's effective context.
