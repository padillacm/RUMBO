# ADR-0020: Adoption follows the layout the project already has
Status: accepted    Date: 2026-11-09

Completes ADR-0013 (adopting an existing project). ADR-0013 stands.

## Context
`rumbo init --adopt` detects the package, the kind, the layout and the tests directory of an
existing project. An audit of v0.4.0 found three places where the harness then ignores what it
detected:

1. **The tests directory.** `[tool.rumbo].tests` is honoured by the sensor and by G4, but gate
   G3 looks for `tests/architecture/test_architecture.py` and `rumbo trace` scans `tests/**`,
   both hard-coded. A project with `test/` fails G3 and traces nothing.
2. **A package outside `src/`.** `detect_package` accepts `<pkg>/__init__.py` at the root, but
   the generated configuration says `src` everywhere: `bandit -r src`, the type checker's
   `include`, `coverage` `source`, the mutation paths and `SRC` in the architecture test.
3. **`{changed}` defeats the exclusions.** A changed file under `spikes/` is passed to ruff and
   to the type checker by name, and a file named on the command line bypasses `extend-exclude`
   and `include`. Prototype code, which the method keeps out of every check, turns the run red.

## Drivers (non-functional requirements)
A project generated by `rumbo init` (always `src/<pkg>`, `tests/`) must not change by a byte.
An adopted project is not asked to move its code. One source of truth per fact, in
`[tool.rumbo]`, readable by the scripts that run without `rumbo` installed.

## Options considered
1. **Require `src/` and `tests/` to adopt.** Rejected: moving the package is the kind of
   invasive first step ADR-0013 exists to avoid.
2. **Derive the source root on every command** by looking at the disk. Rejected: `update` and
   `promote` render configuration later and would guess again; a guess that changes is a bug.
3. **Store it once, like the tests directory (chosen).**

## Decision and rationale
**A new key, `[tool.rumbo].src`.** The directory that holds the package: `"src"` (default) or
`"."`. `--adopt` writes `"."` when the package was found at the root. A project without the key
loads as `"src"`; `rumbo update` writes the key like the other late keys (ADR-0010).

Two values are derived from it for the templates, so that a `src` project renders exactly as
before:

| | `src = "src"` | `src = "."` |
|---|---|---|
| `code_root` (what tools scan) | `src` | `<package>` |
| `package_path` | `src/<package>` | `<package>` |

They replace the literal `src` in `pyproject.toml.tmpl` (bandit, pyright `include` and
`strict`, mypy `files`, coverage `source`, mutation paths) and in `test_architecture.py.tmpl`.

**The tests directory everywhere.** G3 looks for `<tests>/architecture/test_architecture.py`;
`rumbo trace` scans `<tests>/**/*.py` (and `evals/datasets/*.jsonl`, unchanged). Both read
`[tool.rumbo].tests` through the project state.

**`{changed}` never contains `spikes/`.** `resolve_changed` drops every path under `spikes/`:
spikes are not checked, by the same rule that keeps them out of imports and out of ruff. The
generated `[tool.ruff]` also sets `force-exclude = true`, so a project's own exclusions hold
for files named on the command line. `--full` (the whole tree, `.`) is unchanged: there the
tools apply their own configuration.

Not changed: the type checker still checks a changed file outside its `include` (a script, a
`noxfile.py`) when it is named. A changed file is held to the standard; only `spikes/` is exempt.

## Consequences (+/−)
+ A project with `test/` and a package at the root can be adopted and pass G3, G4 and the runner.
+ Prototype code under `spikes/` cannot turn an adopted project's check red.
− One more key in `[tool.rumbo]`.
− `force-exclude` makes ruff slightly stricter about its own excludes in pre-commit; that is
  the behaviour the project asked for when it wrote them.

## Fitness function
`tests/test_scaffold.py::test_adopting_a_root_package_points_every_tool_at_it`,
`::test_a_src_project_renders_as_before`;
`tests/test_gates.py::test_g3_and_trace_follow_the_tests_directory`;
`tests/test_check.py::test_changed_never_includes_spikes`.

## Reversibility: high
