# Audit before v0.4.1 (2026-11-16)

Two sources, measured on `main` at `f6bf966`:

- **H**: the human's second audit (four experts), checked against the code afterwards.
- **A**: six audit agents (guard, sensor, runner and gates, scaffold, templates, verify-dep/tour/docs).
  Each reproduced its findings in throw-away directories; the repository was not modified.

Evidence column: **C** = confirmed afterwards by reading the code; **R** = reproduced by the agent,
not re-read; **U** = not verified. Severity is the reviewer's after checking, not the reporter's.

None of these is a regression of v0.4.0: all of them are in the published version.

## Found solid

- Guard: case variants, trailing dot or space and `::$DATA` on Windows; `..` and `./`; `pyproject_change` fails closed on new, deleted and unparseable files; `commit --amend` runs the hooks.
- Sensor: control gutting is caught; `--strict` with no base exits 2; CRLF; async tests, `match`, nested classes and helper cycles do not crash.
- Runner: configuration errors exit 3; `{changed}` for staged, untracked, deleted and `spikes/` files; a tool missing under `uv run` is ENV.
- Scaffold: `render.py` (GitHub `${{ }}`, nesting, no re-expansion); no path traversal through name or package; the pyproject text merge is idempotent; init then update is a no-op on 26 configurations.
- Templates: the five pinned action SHAs match their tags; every rendered YAML, TOML, JSON and Python file parses; ruff is clean on 20 untested configurations.
- Release: every test named by ADR-0001 to ADR-0021 exists; all 95 requirement ids are mentioned in tests; the wheel carries all 91 files of `src/rumbo`; version 0.4.0 agrees everywhere.

## Decisions for the human

1. **ADR-0018** (R1, R3): probe on exit 1; environment codes per tool.
2. **ADR-0019 / F-0001** (G2, G3): protect the shadow configuration files and `.git/`.
3. **ADR-0017** (G14): an agent cannot create a numbered document without the mark.
4. **ADR-0021** (G7, S2): `agent_env`, `agent_authors` and `tests` are read from `HEAD` or the base.
5. **New mechanism** (G5, G12): the guard remembers `HEAD` between pre-tool and post-tool; Stop verifies committed code.
6. **Permissions** (P2, V6): `make rumbo *`, `rumbo decision *`, `git diff *`, `verify-dep --index`.
7. **Adoption** (C2, C3, C6, C7): what `--adopt` writes when the project already has its own configuration.
8. **`require_live`** (P4): offline as the explicit flag, or a documented production variable.
9. **G5 with one Python** (T7), and **S13** as accepted risks in the threat model.
