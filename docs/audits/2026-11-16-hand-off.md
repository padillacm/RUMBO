## 5. Update the threat model

- Line 51: "package name only, HTTPS" holds for PyPI and OSV; a private index is queried as
  configured, with its credentials (the C4 already says so). Line 95: remove the leftover
  sentence "Mitigation planned: Trusted Publishing once G1 is signed".
- Mitigations table: add rows for "malformed JSON or HTML from an index" and "a slow or
  hanging endpoint" (tests in `tests/test_verify_dep.py`).
- Accepted risks to add, if you accept them:
  - The limits of a syntactic sensor: asserts under a false constant, a helper named like an
    assertion that checks nothing, hollow mock asserts, a widened `pytest.raises`.
  - A push straight to the default branch is compared with the push before it.
  - The guard's state file can be written from the shell; a commit made in the background
    after a command ends is not judged; a project in a sub-directory of its repository is
    judged by the Claude Code hooks but the `pre-commit` hook reads repository-root paths.
  - A token in the path of an index URL is printed; an abandoned request thread lives until
    the process exits.
  - `[tool.rumbo].tests` cannot point at a nested directory: tests found elsewhere are
    collected by pytest but the sensor does not watch them (the report of `init` says so).
- ADR-0013, line 95, names `tests/test_fitness.py`; the test is
  `tests/test_self_adoption.py::test_rumbo_doctor_passes_on_the_repository_itself`.
