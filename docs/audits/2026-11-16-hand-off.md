# Hand-off to the human: slice 7 (second audit)

What only the human can do before this branch is green and can be merged. The agent cannot
edit protected files or signed documents, and the ADR drafts are decisions to accept or reject.

Do steps 1 to 3 and the commit in one go, from your own terminal, **with no agent acting in
this checkout in between**: after `rumbo update` and before your commit, the guard finds
protected files changed and stops the agent. Before `git add -A`, `git status --short` must
list exactly the eleven ADRs, `.claude/settings.json`, `pyproject.toml` and the three scripts.
The steps were rehearsed on a clone on 2026-11-20 (Git Bash and PowerShell 5.1): the check ends
green, your commit passes the hooks, and a second `rumbo update` changes nothing.

## 3. Refresh the harness copies

```

```

It refreshes `scripts/rumbo_check.py`, `scripts/rumbo_guard.py` and
`scripts/check_tests_not_weakened.py`, and writes `own_ci` / `own_infra` in `[tool.rumbo]`.
Until then `tests/test_self_adoption.py` fails and this repository's own hooks run the old
guard. The comment about `{base}` in `pyproject.toml` ("origin/main if it exists, else main")
is stale: the runner now tries `origin/main`, `origin/master`, `origin/HEAD`, `main`, `master`.
